# 两个人的今天

微信原生 + CloudBase 的双人生活记录小程序。首页采用已确认的鼠尾草绿/沙色、紧凑头像天气卡与小时刻度时间轴。

## 当前可以使用

- 统一时间线主页：双人小时轴、双色底色与中线推移；搜索入口保留按月、成员、类型及文字筛选。
- 页面进入、按钮点击、资料弹层和双人分栏过渡动画；清理非功能性抒情文案。

- 点击另一侧头像进入左右中分，再点任一侧展开；日期与时间轴滚动位置保留。
- 三餐、零食、饮料、活动时间段、🩸、排便、自慰记录；页内新增/编辑、删除、备注和最多6张照片。新增记录默认两人可见，已有记录保留原权限。
- 分科学习计时，暂停/恢复/结束、退出应用恢复；统计扣除暂停并合并重叠时段。
- 月/周日历、双色事件圆点、可展开的当天事件列表、成员/类型筛选、跨月事件、日/周/月学习统计、所选年份本人记录JSON导出，照片在详情另存相册。
- 一次性邀请绑定两人、私密/共享权限、对方只读、解绑；云函数校验照片归属并签发短期图片链接。
- 昵称、头像、手动选城市；天气接口与缓存已实现，未配天气凭据时明确显示“天气未接入”。

## 打开

在微信开发者工具中打开本目录并编译。默认是带有提示条的**本机演示**，可立即查看样式和试用记录。演示数据和云端完全分开，不会自动迁移。

真实使用：在首页或“我的”点击**连接云端**。在“我们”中生成口令，让体验成员在自己的微信里输入完成绑定。

- AppID：`YOUR_WECHAT_APPID`
- 云环境：`YOUR_CLOUDBASE_ENV_ID`
- 云函数：`couple`

完整配置、权限规则、天气接入和双手机验收见 [DEPLOYMENT.md](DEPLOYMENT.md)。开发范围见 [DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md)。

## 验证

`npm run check` 检查脚本、JSON、WXML条件绑定、页面文件及共享规则一致性。

`npm test` 包含时间边界、暂停、重叠布局、权限、并发邀请和云函数行为测试（云函数测试使用事务数据库替身）。

`scripts/cloud-smoke.js` 和 `scripts/cloud-photo-smoke.js` 通过已登录的微信开发者工具执行真实云端读写验证，仅使用标记的临时测试记录并清理。`scripts/smoke.js` 只操作演示数据，执行界面切换、表单隐私、保存与删除检查。
