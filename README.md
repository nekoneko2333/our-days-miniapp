# 两个人的今天

基于微信原生小程序与 CloudBase 的双人生活记录应用，把日常、学习与睡眠放进同一份时间线。

## 功能

- 双人空间：一次性邀请绑定、私密与共享记录、解绑及服务端权限校验。
- 日常记录：饮食、活动、身体、学习和睡眠，支持备注、照片、评论与回复。
- 两种首页：事件列表与小时时间轴，支持成员视图和日期导航。
- 学习专注：分科计时、暂停恢复、番茄专注和小程序内悬浮窗。
- 日历与统计：跨日事件、学习与睡眠时长、分类统计和本人年度 JSON 导出。
- 本机演示：无需部署即可体验；连接云端后使用真实双人数据。

## 快速开始

需要 Node.js、npm 和微信开发者工具；云端功能另需自己的微信小程序账号与 CloudBase 环境。

```sh
npm ci
npm run check
npm test
```

1. 在微信开发者工具导入仓库根目录。
2. 将 `project.config.json` 的 `appid` 替换为自己的小程序 AppID。
3. 将 `miniprogram/app.js` 的 `globalData.env` 替换为自己的云环境 ID。
4. 编译并体验本机演示。体验版、正式版的默认连接行为与开发版不同，使用前请确认当前模式。
5. 按 [部署指南](DEPLOYMENT.md) 设置数据库、存储权限并部署 `couple` 云函数，然后连接云端。

仓库中的 AppID、云环境 ID 和通知模板 ID 是原项目的配置标识，不是访问密钥；自行部署必须替换为自己的配置。天气密钥仅配置在云函数环境变量中。

## 开发与验证

```sh
npm run sync         # 修改共享 domain.js 后同步云函数副本
npm run check        # 检查语法、JSON、页面与规则一致性
npm test             # 执行单元及集成测试
```

`scripts/*smoke.js` 等界面脚本依赖已登录的微信开发者工具与自动化端口；云端脚本会访问真实云环境，运行前阅读各脚本与部署指南。自动测试不替代双手机绑定、授权和分享验收。

## 配置与边界

- 数据库集合必须禁止客户端直接读写，统一经过云函数验证身份和可见性。
- 私密权限属于应用访问控制，云环境管理员仍可访问底层数据，并非端到端加密。
- 天气与订阅消息需要另行配置服务凭据、模板及用户授权。
- 进行中的计时草稿保存在当前设备，结束保存后同步；另一设备通过页面刷新获取记录。
- 年度导出中的照片为引用，原图需要单独保存。
- `node_modules/`、`output/`、本机开发者配置和密钥文件不纳入版本管理。
